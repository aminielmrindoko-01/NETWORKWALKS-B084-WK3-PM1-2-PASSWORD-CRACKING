### Evidence-path note

The Module 1 evidence was uploaded under a legacy path containing literal backslashes (`labs\01-john-the-ripper\screenshots`) instead of standard directory separators. GitHub treats that as a differently named path, so ordinary links to `labs/01-john-the-ripper/screenshots/` will not resolve to those original images. The Module 1 notes identify the legacy location. The evidence files have been left intact.

The `shot-1` entry previously present in the Module 2 screenshots folder is a one-byte placeholder without a file extension, not a usable screenshot. The actual screenshots are the PNG files listed above.
